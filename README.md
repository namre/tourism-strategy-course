# Маркетинговые стратегии в сфере туризма

Интерактивный курс для магистратуры по направлению 43.04.02 «Туризм». Подходит для занятий в аудитории и для самостоятельной работы: все материалы, задания, критерии и разборы открыты.

Сайт: https://namre.github.io/tourism-strategy-course/

## Что внутри

- 17 уроков в четырёх модулях: от постановки стратегического вопроса и исследования клиента до экономики каналов, цен, решений при неопределённости, продвижения, экологического обещания и защиты стратегии. Учебный кейс уроков — городской отель «Маяк».
- 14 схем и 7 интерактивов прямо в уроках (полоса мощности, тарифный барьер, пороги смены решения, цена переноса дат, «двадцать пилотов», своя мощность для экотропы и экскурсий) и видео об интервью с субтитрами.
- Тренажёр экономики каналов: решение до и после появления календаря спроса.
- Сквозной проект на 118 часов самостоятельной работы: семь контрольных точек по своей организации или открытому кейсу Астраханской области.
- Документы для сдачи в привычных форматах: выгрузка ответов в Word с титульным листом по ГОСТ 7.32, шаблоны Word и PowerPoint, рабочая тетрадь Excel с формулами, печатные памятки в PDF.
- Страница «Как работать с курсом» — порядок самостоятельной работы, формат занятий в аудитории, часы, литература.

Ответы хранятся только в браузере на текущем устройстве; резервную копию можно скачать и восстановить в разделе «Материалы».

## Локальный запуск

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Открытие `index.html` через `file://` не подходит: браузер блокирует модули JavaScript. Зависимостей npm нет.

## Проверки

```sh
npm test                       # содержание, расчёты, импорт, часы проекта, запрещённые формулировки
python3 tests/browser_smoke.py # сценарий в браузере (Playwright + Chromium)
```

## Устройство

- `course-data.js` — уроки, тесты, словарь, рубрика; `capstone-data.js` — сквозной проект и руководство.
- `media-map.js` — где в уроках стоят схемы (`figures/*.svg` + `.json` с подписью и текстовой версией), интерактивы (`widgets/*.js`, у каждого `compute()` с тестами) и видео (`media/`, исходник сцен — `media/src/`).
- `docx-gost.js` — сборка документов Word по ГОСТ 7.32 (в браузере через `vendor/docx.iife.js`, библиотека docx, лицензия MIT).
- `templates/` и `data/` — шаблоны и таблицы для студентов; пересборка: `tools/build-office.sh` (Node с пакетами docx и pptxgenjs, Python с openpyxl, LibreOffice).
- `engine.js` — расчёты тренажёра и проверка импортируемого прогресса; `app.js`, `index.html`, `styles.css` — интерфейс без сборки.
