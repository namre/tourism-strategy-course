# Маркетинговые стратегии в сфере туризма

Интерактивный курс для магистратуры по направлению 43.04.02 «Туризм». Подходит для занятий в аудитории и для самостоятельной работы: все материалы, задания, критерии и разборы открыты.

Сайт: https://namre.github.io/tourism-strategy-course/

## Что внутри

- Уроки по четырём модулям: от постановки стратегического вопроса и исследования клиента до экономики каналов, решений при неопределённости, продвижения и защиты стратегии. Учебный кейс уроков — городской отель «Маяк».
- Тренажёр экономики каналов: решение до и после появления календаря спроса.
- Сквозной проект на 118 часов самостоятельной работы: семь контрольных точек, по которым студент строит стратегию для своей реальной организации или для открытого кейса Астраханской области.
- Итоговая стратегия с рубрикой и выгрузкой в Markdown или PDF.
- Страница «Как работать с курсом» — порядок самостоятельной работы, формат занятий в аудитории, часы рабочей программы, литература.

Ответы хранятся только в браузере на текущем устройстве; их можно выгрузить в JSON и Markdown в разделе «Материалы».

## Локальный запуск

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Открытие `index.html` через `file://` не подходит: браузер блокирует модули JavaScript. Зависимостей npm нет.

## Проверки

```sh
npm test                       # содержание, расчёты, импорт, часы проекта, запрещённые формулировки
python3 tests/browser_smoke.py # сценарий в браузере (Playwright + Chromium)
```

## Устройство

- `course-data.js` — уроки, тесты, словарь, рубрика.
- `capstone-data.js` — сквозной проект и руководство по работе с курсом.
- `engine.js` — расчёты тренажёра и проверка импортируемого прогресса.
- `app.js`, `index.html`, `styles.css` — интерфейс без сборки.
- `data/case.csv` — параметры пакетов продаж учебного кейса.
