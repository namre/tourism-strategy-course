# Маркетинговые стратегии в сфере туризма

Полный интерактивный учебный курс для магистрантов: 4 модуля, 12 уроков, индивидуальные задания, 24 вопроса с объяснениями, тренажёр экономики каналов и итоговая стратегическая записка.

Курс разработан для 16 академических часов занятий и 20 часов самостоятельной работы. Отель «Маяк», интервью и числовые данные полностью синтетические. Рыночная достоверность материалов и образовательная результативность требуют независимой экспертизы и пилота.

## Запуск

Нужны Python 3 и современный браузер:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. Открытие `index.html` через `file://` не подходит: браузер блокирует импорты модулей JavaScript. Зависимостей npm нет.

## GitHub Pages

В репозитории откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**, выберите **main / (root)** и сохраните. Это статическое приложение без сборки и серверных секретов. При имени репозитория `tourism-strategy-course` адрес аккаунта namre будет https://namre.github.io/tourism-strategy-course/ после успешной публикации Pages.

Весь курс можно разместить и в подпапке другого репозитория: ссылки относительные. Публикуемый URL в этом случае включает имя репозитория и подпапку. Наличие исходников в GitHub само по себе не подтверждает публикацию Pages.

## Как проходить

1. Изучите урок и запишите индивидуальное решение.
2. Ответьте на вопросы: объяснения доступны после проверки, попытки не ограничены.
3. После записи решения и успешного теста отметьте урок завершённым.
4. В тренажёре сохраните первоначальный выбор, откройте календарь, измените предположения и запишите пересмотр.
5. Соберите итоговую стратегию; скачайте Markdown или напечатайте в PDF.
6. Передайте работу преподавателю для оценки по рубрике.

## Сохранение и ограничения

Ответы хранятся в `localStorage` только в текущем браузере и на текущем адресе сайта. Они не отправляются на сервер, в GitHub или преподавателю. При очистке браузера возможна потеря данных; резервная копия JSON находится в разделе «Материалы». Смена домена не переносит данные автоматически. Рабочую тетрадь и итоговую записку можно выгрузить в Markdown. Не вводите персональные данные реальных гостей.

Общей ведомости, регистрации и серверной проверки нет. Автоматические тесты проверяют понимание отдельных положений; они не заменяют экспертную оценку стратегии. Публичные ключи и возможность повторных попыток делают приложение учебной средой, а не защищённым экзаменом. Отметка прохождения не является сертификатом.

## Проверка и устройство

```sh
npm test
```

Тесты используют встроенный модуль Node.js (версия 20 или новее). Проверяются полнота уроков, экономика каналов, расходы при отменах, календарное вытеснение, пороги выбора и импорт прогресса. Браузерный smoke-сценарий находится в `tests/browser_smoke.py` и требует Python Playwright и Chromium; он не нужен для запуска курса.

- `course-data.js` — содержание и квизы;
- `engine.js` — расчёты и проверка структуры прогресса;
- `app.js` — навигация, задания, сохранение, экспорт и тренажёр;
- `styles.css` — адаптивный интерфейс и печать.

Учебная модель фиксирует непиковый спрос; ползунки меняют пиковый базовый спрос и его маржинальность. Это анализ чувствительности, а не оценка реальной эластичности спроса.
